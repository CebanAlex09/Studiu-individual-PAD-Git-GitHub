# Problema Damelor – Aplicație în C++ (Visual Studio)

O aplicație consolă realizată în limbajul C++ în mediul Microsoft Visual Studio, care rezolvă problema clasică a așezării celor N dame pe o tablă de șah fără a se ataca reciproc.

## Despre Proiect

Acest proiect reprezintă o lucrare practică de programare în C++. Scopul lucrării este implementarea algoritmului de tip Backtracking pentru determinarea tuturor soluțiilor 
valide în care N regine pot fi plasate pe o tablă de dimensiune N×N, precum și gestionarea versiunilor codului prin Git și GitHub.

## Caracteristici

- **Limbaj și mediu de dezvoltare:** Cod sursă scris în C++ (`Problemadamelor.cpp`), compilat și depanat în Microsoft Visual Studio.
- **Algoritm utilizat:** Metodă Backtracking pentru verificarea și generarea tuturor configurațiilor valide pe tablă.
- **Documentație inclusă:** Enunțul detaliat al problemei salvat în format `.docx` (`Enuntul problemei.docx`).
- **Securitate și organizare:** Configurarea fișierului `.gitignore` pentru a exclude datele sensibile (`Parole.txt`) din repository-ul public.
